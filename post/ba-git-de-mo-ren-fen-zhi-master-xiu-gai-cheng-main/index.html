把git的默认分支master修改成main

2023-03-26 1 分钟阅读 # git # github

修改初始化项目时，默认使用main作为主分支

git config --global init.defaultBranch main

已经创建项目的主分支为master，切换到master分支，重命名main

git branch -M main
