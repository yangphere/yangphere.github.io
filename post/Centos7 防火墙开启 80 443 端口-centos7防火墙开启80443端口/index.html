Centos7 防火墙开启 80 443 端口

2019-11-03 1 分钟阅读 # linux # centos

启用防火墙

systemctl start firewalld.service

开启 80 443 端口

firewall-cmd --zone=public --add-port=80/tcp --permanent
firewall-cmd --zone=public --add-port=443/tcp --permanent

重启防火墙

firewall-cmd --reload
